# StudyFlow Revised Sitemap

This sitemap was created from the three participant card-sort result sets supplied for the StudyFlow Phase 2 project.

## Proposed primary navigation

1. **Tasks**
   - All Tasks
   - Create Task
   - Task Details
   - Task Actions (Edit, Delete, Mark Complete)

2. **Find & Organize**
   - Search Tasks
   - Filter by Course
   - Filter by Priority
   - Sort by Due Date

3. **Progress & Deadlines**
   - Pending Tasks
   - Completed Tasks
   - Overdue Tasks
   - Upcoming Deadlines
   - Task Progress

The Dashboard is the landing page. The global header contains account/profile and help utilities. Contextual actions appear when a user is viewing a task; they are not separate primary navigation destinations.

## Evidence from the card sort

- All 3 participants grouped Create, Edit, and Delete together.
- All 3 grouped Search, Filter by Course, and Filter by Priority together.
- All 3 grouped View Completed Tasks and View Pending Tasks together.
- All 3 grouped View Overdue Tasks and View Upcoming Deadlines together.
- View Task Progress was grouped with Completed/Pending by all 3 participants.
- Sort by Due Date was grouped with deadline/tracking features by P02 and P03, while P01 grouped it with task organization.
- Mark Complete was grouped with progress/tracking by P01 and P02, while P03 grouped it with task actions.
- View Task Details was grouped with task management/actions by P01 and P02, and with task navigation by P03.

## Design decisions

- **Mark Complete is a contextual task action.** The participants disagreed about whether it belongs with task actions or progress tracking. Placing it on the task row/details screen makes it available where the user acts on a specific task, while the Progress & Deadlines area remains focused on viewing status.
- **Sort by Due Date is shown under Find & Organize.** P01 grouped it with organization, while P02/P03 associated it with deadlines. Sorting is an organization control, so placing it beside search and filters provides a predictable way to change the task list order. The deadline views remain in Progress & Deadlines.
- **Task Details is reached by selecting a task.** It is not necessarily a permanent menu item; it is a contextual destination from All Tasks or search results.
- **Completed, Pending, Overdue, Upcoming, and Progress are grouped together** because participants consistently associated status and deadline views.

## Navigation types

- **Global navigation:** StudyFlow brand/header, profile/account, help.
- **Primary navigation:** Dashboard, Tasks, Find & Organize, Progress & Deadlines.
- **Secondary navigation:** All Tasks, Create Task, Search, filters, sorting, status/deadline views.
- **Contextual navigation:** Task Details, Edit, Delete, Mark Complete, breadcrumbs, and inline links.

## Notes / validation

This sitemap is a design interpretation of the submitted card-sort results, not a direct copy of any single participant's categories. It should be checked in later usability testing to confirm that users can locate tasks and understand the navigation labels. The uploaded results also contain differing session dates between individual notes and the session log; verify the dates in the source records if they will appear in the final report.
