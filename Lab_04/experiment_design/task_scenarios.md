# Task Scenarios – Student Task Manager Experiment

## Purpose

Participants will complete two equivalent task-creation scenarios while testing Interface A (single-page form) and Interface B (multi-step wizard).

Both scenarios require participants to enter the same five types of information:
- Task title
- Description
- Course
- Due date
- Priority

The scenarios use different academic tasks to reduce the likelihood that participants simply repeat the exact same information during the second condition.

## Scenario 1 – Research Summary

**Participant instructions:**

You have been assigned a reading assignment for one of your college courses. Add the following assignment to your Student Task Manager.

| Field | Information |
|---|---|
| Task Title | Chapter 4 Research Summary |
| Description | Read Chapter 4 and write a one-page summary of the main concepts. |
| Course | PSY 210 |
| Due Date | 14 days after the study session |
| Priority | High |

## Scenario 2 – Database Worksheet

**Participant instructions:**

You have been assigned a worksheet for one of your college courses. Add the following assignment to your Student Task Manager.

| Field | Information |
|---|---|
| Task Title | Database Design Worksheet |
| Description | Complete the worksheet covering entity relationships and database normalization. |
| Course | CS 240 |
| Due Date | 14 days after the study session |
| Priority | High |

## Scenario Assignment and Counterbalancing

Six participants will be divided equally between the two interface orders.

| Participant | Interface Order | Period 1 Scenario | Period 2 Scenario |
|---|---|---|---|
| P01 | A → B | Scenario 1 | Scenario 2 |
| P02 | B → A | Scenario 1 | Scenario 2 |
| P03 | A → B | Scenario 1 | Scenario 2 |
| P04 | B → A | Scenario 1 | Scenario 2 |
| P05 | A → B | Scenario 1 | Scenario 2 |
| P06 | B → A | Scenario 1 | Scenario 2 |

This assignment ensures that each interface receives Scenario 1 three times and Scenario 2 three times.

The due date should be calculated as 14 calendar days after each participant's study session. Use the same date for both scenarios within that participant's session.

## Researcher Instructions

1. Give participants only the scenario assigned for their current testing period.
2. Read the scenario instructions exactly as written.
3. Do not tell participants where to find fields or how to complete the task.
4. Use the same scenario information for every participant assigned to that scenario.
5. Record the scenario number in the participant data collection sheet.
6. Verify that the task was successfully saved before stopping the timer.

## Scenario Consistency

Both scenarios require the same number of fields, use the same priority level, and have equivalent due dates. This helps control task difficulty so that differences in performance are more likely to reflect the interface design rather than differences between the assigned tasks.
