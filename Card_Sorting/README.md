# StudyFlow — Card Sorting Files

## Folder contents
- `card_deck.csv` — 15-card deck.
- `p01_card_sort.csv`, `p02_card_sort.csv`, `p03_card_sort.csv` — participant-level results.
- `p01_session_notes.md`, `p02_session_notes.md`, `p03_session_notes.md` — session records.
- `session_log.csv` — session metadata.
- `all_participant_results.csv` — combined results.
- `similarity_matrix.csv` — pairwise co-sorting counts.
- `analysis.md` — findings and IA interpretation.
- `participant_data_template.csv` — results.
- `printable_card_deck.pdf` — printable participant cards and instructions.
